НАШИ ТРАТЫ — файлы приложения

index.html            — само приложение
config.js             — настройки (сюда вставляешь данные Firebase и ваши почты)
manifest.webmanifest  — чтобы приложение ставилось на телефон с иконкой
sw.js                 — чтобы открывалось быстро и без интернета
icons/                — иконки
firestore-rules.txt   — правила доступа к базе (вставляются в Firebase, на GitHub не нужны)
